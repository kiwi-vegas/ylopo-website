Critical Issues Costing You Traffic Now

Every page uses the identical meta description

On-Page Structure

H1 Misuse — Broken Across Product Pages

Google uses H1 to determine a page's primary topic. Multiple H1s send conflicting signals.

PageH1 CountStatus
/real-estate-lead-nurture9 H1sCritical
/crm-integration8 H1sCritical
/mission-control6 H1s + 0 H2sCritical
/idx-home-search6 H1sCritical
/convert-buyersMultipleHigh
/ai-for-real-estate3 H1sHigh
/pricing2 H1sHigh
/blog0 H1sHigh

Why this matters

  • Google reads H1 as the primary topic signal for a page
  • Multiple H1s = Google can't determine which one to rank for
  • Feature names marked as H1 instead of H2 is the main culprit — likely a Squarespace component styling issue
  • /mission-control has 6 H1s and zero H2s — no hierarchy at all

The Fix

Each page needs exactly one H1 (the page headline). Feature section titles should be H2. Sub-points should be H3. This is a CSS/template fix in Squarespace — change heading component defaults from H1 to H2.

AI Search Readiness

Invisible to AI — A Strategic Blind Spot

Real estate agents increasingly ask ChatGPT and Perplexity "what's the best lead gen platform?" Ylopo doesn't appear.

🚫 robots.txt blocks AI crawlers

Listed in Disallow block: GPTBot, ClaudeBot, anthropic-ai, Google-Extended (Gemini), cohere-ai. These bots power ChatGPT, Claude, Gemini, and Cohere — the four largest AI answer engines.

🚫 No llms.txt file

llms.txt is an emerging standard (2024–2025) that lets you tell AI crawlers exactly what to ingest and how to understand your company. Ylopo has none. Zero AI-curated guidance exists.

⚠️ JS-rendered content

Homepage and product pages are heavily JavaScript-rendered via Squarespace. AI crawlers that don't execute JS (many don't) see thin or empty content. Plain-text content is the exception, not the rule.

Highest Impact: FAQPage Schema

The /faq page has content, and multiple product pages have FAQ sections. Adding FAQPage schema to these pages enables accordion FAQ boxes directly in Google search results — doubling SERP real estate for those queries at no ad cost.

AggregateRating on /reviews

Ylopo has documented success stories with specific ROI numbers. Adding Review/AggregateRating schema to /reviews would enable star ratings in branded search results. High-trust signal for agents evaluating the platform.

Event schema on all webinar pages

100+ webinar pages use Article schema. Switching to Event schema makes them eligible for Google Event rich results with date, time, and registration links visible in SERPs.

JSON-LD Template

{
  "@context": "https://schema.org",
  "@type": "FAQPage",

      "name": "Does Ylopo work for solo agents?",
      "acceptedAnswer": {
        "@type": "Answer",
        "text": "Yes. Ylopo's Suite plan
is designed for individual agents..."

</script>
