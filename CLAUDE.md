# Ylopo Website

@CLAUDE-WAT.MD

## Project Context

This project builds the **Ylopo marketing website**. The goal is to design, build, and iterate on the public-facing site using the WAT framework.

## Project-Specific Rules

- All website deliverables go in the project root as `index.html` (single-file builds) or in a `src/` directory for multi-page builds.
- Workflows for this project live in `workflows/`. Tools live in `tools/`.
- Brand assets (logos, color palettes, style guides) live in `brand_assets/`. Always check there before designing anything.
- Credentials and API keys go in `.env` only — never hardcoded.
